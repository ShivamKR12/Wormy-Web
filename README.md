# Wormy (Web Edition)

A classic Nibbles / Snake arcade game built with Python and Pygame-CE. Slither around to collect apples and achieve a high score.

Playable locally and in modern web browsers via WebAssembly ([Pygbag](https://pygame-web.github.io/)).

## How to Run Locally

### Prerequisites
- Python 3.10+
- `pip install pygame-ce pygbag`

### Play Locally
```bash
python main.py
```

### Run in Browser Locally
```bash
python -m pygbag main.py
```
Open `http://localhost:8000` in your web browser.

## Controls
- **Arrow Keys** or **WASD**: Steer worm
- **Escape**: Quit game
